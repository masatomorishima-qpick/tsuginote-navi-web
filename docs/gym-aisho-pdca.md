# パーソナルジム相性診断（/gym/aisho）改善の手順

## 狙い
ジムが個室化して口コミが効きにくい。満足を決めるのは店より「担当トレーナーとの相性」。
7問で「合うトレーナーのタイプ」と「ジムを選ぶ条件」を出し、条件に合う提携ジムの体験へ送る。
結果のあとの任意アンケート（辞めた理由・知りたかったこと）は、診断の改善と、トレーナー紹介の事業を検討する材料にする。

## 集客
- 主はソーシャルメディア広告（Instagram など）。「パーソナルジム 選び方」の検索は月140回程度と小さい。
- 広告の URL には `utm_source` / `utm_campaign` / `utm_content`（クリエイティブ名）を必ず付ける。
- 各案件の掲載ルールで、ソーシャルメディア広告からの送客が許可されているかを先に確認する。

## 紹介先を出すまでの手順（lib/gym/aisho.ts の PARTNERS）
1. 案件が承認されたら、管理画面の報酬・成果地点を書き写す。
2. 次の4つを公式サイトや相談事例で確認する。
   - 料金の総額を公開している
   - 解約・返金の条件を公開している
   - 体験当日の契約を迫らない
   - ソーシャルメディア広告からの送客が許可されている
3. 全部満たしたら `href` に案件リンクを貼り、`vetted: true` にする。
4. `points` には公式情報で確かめた事実だけを書く（「必ず痩せる」などの言い切りは書かない）。
5. 女性専用のジムは `only: 'female'`。「女性トレーナーがいい」と答えた人にだけ出る。

いまは ボディアクシス（レントラックス・提携中）と GYMS（A8）の枠だけ用意してある。どちらも href は空なので、紹介先は表示されない。

## 毎週見るもの（supabase/queries/gym_aisho_funnel.sql）
| 見るもの | 目安 | 低いときに触る所 |
|---|---|---|
| 開始 → 結果 | 70%以上 | 離脱が多い設問の選択肢を減らす |
| 結果（紹介先あり） → クリック | 15%以上 | 紹介先の並び・ボタン文言 |
| 広告別の開始数と単価 | クリック単価 ÷ 送客率 ≦ 報酬×確定率×0.7 | 広告の停止・差し替え |
| アンケート完了率 | 20%以上 | 設問数を減らす |

## 版の管理
診断の文言・分岐・アンケートを変えたら `VERSION` を上げる。GA4 と lp_event_logs の両方に毎回送っているので、版ごとに比べられる。
