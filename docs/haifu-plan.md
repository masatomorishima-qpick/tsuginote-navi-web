# 無料の配布物で人を呼び、紹介料で稼ぐ（2026-11-04 夜、オーナー「全て進めて」「ツールを無料で配ることで流入が稼げるならどんどん伸ばしたい」）

## 結論
- 勝ち型は「〇〇 一覧表／管理表／テンプレート／エクセル」の言葉に、無料の表を配るページで答えること。保険の一覧表は、この型の言葉で4〜7位・クリック率5〜11%を取っている（下の事実）。
- 次に作る配布物は、**サイトの得意な領域（相続・もしもの備え・親のこと）で、紹介料が高い出口があるもの**から。給湯器は領域の外で上がりにくいが、相続まわりは Google がすでにこのサイトの領域と見ている。
- 出口は1ページ1つ。11/4 22:30 に A8 の画面で報酬・成果の条件・1クリックの稼ぎ（EPC）を確かめた（下の「紹介先の表」）。
