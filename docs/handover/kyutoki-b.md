# 引き継ぎ：給湯器 B（自社の取り次ぎ）の立ち上げ（2026-11-01 21:50 作成）

あなたは、合同会社（オーナー：森嶋）の新しい事業「給湯器 B：自社の取り次ぎ」の立ち上げ担当です。ASP（A8 など）経由の送客とは別の取り組みで、オーナーの指示は「スケジュールを前倒しして最短で進める」「業者2社を早々に決める」です。

## 守ること（最優先）
- 返事は日本語だけ。英語・英語の略語・カタカナの専門用語を混ぜない（Google 広告の画面の名前、道具名 Clarity・GA4・Supabase は可）。
- 事業責任者として論理的に。提案は「結論・基準・根拠・失うもの・次の手」。途中で結論を変えない。
- 決めたことは提案で止めずに即実行する。ただし次はオーナーだけが行う：お金を使う操作（配信の開始・停止・予算・入札・新しいキャンペーンや組の作成）、変更依頼の取り込み、本番の公開のやり直し、業者や利用者へのメール・フォームの送信、契約の締結、パスワードの入力、データやキャンペーンの削除。了承をもらったものだけ実行する。
- 利用者や業者が読む文は、優秀な日本語校閲の水準で、普段使う自然な言葉にする。ページは文字を減らして図・アイコン・余白で見せる。
- 検索広告で競合他社の社名は買わない。検索パートナーへの配信は絶対に有効にしない。
- Supabase は SELECT だけ。GitHub の「Suspend／Uninstall」には触らない。ログインボタンは押さない。

## 事業の形（オーナー決定 11/1）
| 誰が | 誰に | 何を | 対価 |
|---|---|---|---|
| 当方（つぎの手ナビ） | 利用者 | 本体込みの総額の目安（診断）、要件に合う業者2社の紹介、現地調査の日程調整 | 無料 |
| 利用者 | 当方 | 地域・号数・機能・希望時期・写真、連絡先、業者に渡すことへの同意 | — |
| 当方 | 業者 | 要件と写真がそろい、日程も決まった現地調査 | — |
| 業者 | 当方 | 面談（現地調査）が済むごとに紹介料 | 5,000円（最初の1か月は無料） |
| 業者 | 利用者 | 現地調査・見積もり・工事 | 工事代金（当方は関わらない） |

- 1人の相談を2社の現地調査につなぐのが基本（複数の見積もりを望む人向け。1社だけだと採算線に届きにくい）。
- 業者とは ASP を通さず直接契約。請求は「面談が済んだら」。無断キャンセルは請求しない。
- 利用者とのやり取り・日程調整は、オーナーが作った AI メールの仕組み（返事の下書きを作り、担当が確認して送る）で行う。最初はオーナーが全通確認してから送る。
- 合同会社は設立済み。適格請求書の番号は持っていない（下の「先に決めること」）。契約の主体は合同会社。

## 1件の流れ
1. 診断（/kyutoki/oyu-ga-denai）の結果画面で「2社から総額の見積もりを受け取る（無料）」にメールを入力（同意つき）
2. 1時間以内に受付メール：5つ聞く（市区町村、今の号数と機能、希望時期、本体の写真、マンションか戸建てか）
3. 返信を要件票にまとめる。足りなければ1回だけ聞き直す
4. 業者を2社選び、要件票と写真を送って、受けられるかと候補日3つを聞く（返事は24時間以内）
5. 利用者に候補日を選んでもらう → 両方に確定の連絡、前日に念押し
6. 翌日、両方に済んだかを聞き、両方が「済んだ」と答えたら完了
7. 月末に業者へ請求

## KPI（判定の数字）
- 北極星：面談の完了件数と、1件あたりの原価（広告費÷完了件数）。合格線は3,500円以下（売価5,000円で粗利30%）。
- 全体の線：クリック単価150円なら、2社につないで「クリック46件ごとに面談1人分（2社）」。
- 段ごとの合格線：クリック→診断の結果 25%（実測16%、10/29〜30 の38→6）／結果→メール入力 40%／入力→要件がそろう 60%／要件→業者が受ける 90%／受ける→日程確定 80%／確定→面談完了 90%。
- 毎日見る数：入力数、返信までの時間、業者の返事までの時間、完了数、広告費。判定は入力20件か11/30の早い方。

## 先に決めること（オーナーに了承をもらう）
1. 適格請求書：番号なしでも始められる（相手が仕入れ税額の一部を差し引けないだけで、5,000円なら差は数百円）。最初は「税込5,000円・番号なし」で約束事に明記し、業者から求められたら登録を検討する案を推す。経過措置の割合と登録の要否は税理士に確認する、と添える。
2. 集客の入口（再開は協力業者が2社決まってから。オーナー 11/1 22:01）：今、診断のページには広告がほぼ来ていない（症状の言葉の組は止めてある。動いている給湯器の組 A2・A7・A9・A10 は記事型 /kyutoki/kokan-hiyou 行きで、ASP 側の検証中なので混ぜない）。B の入口は「複数の見積もりを望む言葉」（例：給湯器 交換 相見積もり、給湯器 交換 見積もり 比較、給湯器 一括見積もり）が意図に合う。新しい広告グループ（完全一致、上限150円、日予算は今のキャンペーンの2,000円の内で）を作る案を、言葉・金額つきで出して了承をもらう。
3. 業者に渡す個人情報の範囲：要件票と写真と市区町村まで。氏名・電話・住所は日程が確定してから渡す。
