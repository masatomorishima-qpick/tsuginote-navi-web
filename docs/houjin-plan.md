## 狙う客と立ち位置（2026-11-24 見直し。オーナー「狙っていたのは新規法人設立の顧客。ターゲット戦略も加味しているのか」）
- 客の分け方：S1 設立前（自分で作るか・どこに本店を置くか）／S2 設立直後〜2か月（届出・口座・会計。口座が開かないと仕事が始まらない）／S3 運営が回り始めた会社（銀行の乗り換え・経費）。
- 狙う客：S2（設立直後〜2か月の1人・少人数の会社）。理由：①悩みが急で具体的（口座の審査に落ちる・何を出せばいいか分からない）②運営会社の実体験がちょうどここ（2026/10/28 設立、3行に申し込み、PayPay銀行で開設）③紹介先が合う：ラクスルバンクは、比べた4行のうち設立直後に補う書類として事業計画書（署名・捺印）を挙げている唯一の銀行（kouza-hitsuyou-shorui の一次情報）、申込1件10,000円・確定率100%。
- 立ち位置：「設立したばかりの1人会社が、口座を開くまでの記録」。銀行・会計ソフト・大手の比較の媒体は一般向けで、設立直後・落ちた実例・1人会社の目線がない。
- 言葉：S2 の入口は「会社設立 後 やること」140・「法人成り 手続き」110・「会社設立 後 手続き」70・「合同会社 銀行口座」70・「合同会社 設立 後 やること」50、口座の段で「法人口座 開設」2,900・「法人口座 ネット銀行」880・「法人口座 作れない」140。「法人口座 開設」は S3 も混ざるので、柱のページは題名の前に「設立直後」を置き、S2 に絞る（量より申込に近さ）。
- 同じ客の2つ目の紹介先（候補・提携はオーナー）：S1〜S2 の本店の住所 → NAWABARI（バーチャルオフィス、A8、新規契約9,000円・確定率81.81%）。
