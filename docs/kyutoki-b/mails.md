# メールの雛形（案）— 2026-11-02 下書き

> AI メールの仕組みで下書きを作るときの元。{ } は差し込み、〔 〕はオーナーが埋める所。最初はオーナーが全通を確かめてから送る。
> 利用者向けの全通の末尾に「送信者の表示と配信停止の案内」を付ける（特定電子メール法）。

## 共通の末尾（利用者向け）
```
――――――――――
このメールは、つぎの手ナビで給湯器の見積もりをご依頼いただいた方にお送りしています。
今後のご連絡が不要な場合は、このメールに「停止」とだけ書いて返信してください。
つぎの手ナビ（〔合同会社の正式名称〕）
〔住所〕／support@tsuginotenavi.jp
```

## 利用者向け 1：受付（入力から1時間以内が目標）
件名：【つぎの手ナビ】給湯器の見積もりのご依頼を受け付けました
```
つぎの手ナビです。
給湯器の見積もりをご依頼いただき、ありがとうございます。

ご入力いただいた条件
・{種類}／{住まい}／{都県}
・使用年数：{年数}　機能：{機能}　号数：{号数}
・交換したい時期：{時期}

お住まいに合う工事会社を2社お選びするため、
次の3つを、このメールへの返信でお知らせください。

1. 市区町村（例：世田谷区）
2. 給湯器の写真2枚（本体の正面と、ラベル）
   ラベルは本体の側面か前面にあり、号数と製造年が書いてあります。
   撮りにくい場合は、なくてもかまいません。
3. 現地調査に来てもらいやすい曜日と時間帯（例：平日の夜、土日の午前）

お返事をいただいてから、1日以内に2社の候補日をお送りします。
```
