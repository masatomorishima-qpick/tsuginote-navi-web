# 給湯器 B：KPI から逆算したページの組み替え（2026-11-02 作成）

## オーナー決定（11/1 22:08〜22:12）
- 11月の目的は「双方に得がある形（業者・利用者・当社）になるか」の検証。業者は最初の1か月無料、広告費は5万円程度。
- 業者候補は40社に声かけ（返事が1〜2割の前提で2社を確実に決めるため）。候補はくらしのマーケット以外の出典から選ぶ。一覧と連絡先はリポジトリに置かない。
- 着地のずれ（相見積もりの言葉 → お湯が出ない診断）は、ページを直して解消する。
- 診断ページは今のままではなく、KPI から逆算して仕切り直す（オーナーの問い 22:12 → 下の結論）。

## 結論
今の診断（/kyutoki/oyu-ga-denai）は A（ASP の1社に送る）のための作りで、B の段の数字に合わない。作り直しではなく、B 専用の「見積もりの条件チェック」（/kyutoki/mitsumori）を新しく作り、今の診断はお湯が出ない（急ぎ）の人向けにそのまま残す。

## 逆算（段ごとの合格線と、ページが受け持つ所）
| 段 | 合格線 | 今の実測 | 受け持ち | 組み替えでやること |
|---|---|---|---|---|
| クリック→結果 | 25% | 16%（38→6、10/29〜30） | ページ | 交換を決めた人に合う質問の順。答えるたびに液晶の表示に「総額の目安」が出る（答える理由） |
| 結果→メール入力 | 40% | 未計測 | ページ | 結果は「総額の目安」と「2社から見積もり」の2つだけ。名前・電話は聞かない |
| 入力→要件がそろう | 60% | 未計測 | メール | 号数・機能・住まい・時期はページで聞いておき、メールで聞くのは市区町村・写真・都合のよい曜日だけ |

- 掛け合わせ：25%×40%×60%×90%×80%×90%＝3.9%（クリック→面談1人分＝2社）。
- 予算5万円・平均104円で約480クリック → 合格線どおりなら入力48件・面談19人（2社で37件）、面談1件の原価 約1,350円。今の16%のままなら入力31件・面談12人（24件）、原価 約2,100円。
- 入力20件に要るのは、合格線どおりで200クリック（約2.1万円）、16%のままで約310クリック（約3.2万円）。5万円で判定の数は足りる。

## なぜ今の診断ではだめか
1. 6問のうち症状・凍結の2問は止める判定のためにあり、業者が欲しい条件（号数・機能・時期・住まいの形）を1つも聞いていない。
2. 1問目の「どんな症状ですか？」は、交換を決めて見積もりを探している人に合わない（開始しない44%、途中でやめる57%）。
3. お湯が出ない（急ぎ）の人は、メールで2〜3日かかる流れを待たずに駆けつけを呼ぶ。B の入口には向かない。

## 新しいページ（/kyutoki/mitsumori）
- 7問：種類 → 住まい（戸建て・分譲マンション・賃貸）→ 地域 → 使用年数 → 機能 → 号数 → 時期。止めるのは種類（ガス以外）・賃貸・1都3県の外。
- 機能を答えた時点から、液晶の表示が「総額の目安 15-20万」に変わる。
- 結果：本体・工事込みの総額の目安（東京ガスの相場、出典つき）、「一覧サイトの表示＝工事費だけが多い／この見積もり＝本体込みの総額」の対比、メール入力欄（同意つき・電話番号は日程が決まるまで伝えない）。
- 時期「すぐ」の人には「現地での見積もりは早くて翌日〜2日後。今日中ならガス会社のほうが早いこともある」と正直に出す。
- 総額の目安は、業者2社が決まったら両社の実際の価格に差し替える（価格の合う人だけが来るので、業者にも利用者にも得）。

## 計測
- lp_event_logs（lp_id = kyutoki-mitsumori）：lp_view → kyutoki_m_start → kyutoki_m_answer（n＝何問目）→ kyutoki_m_stop／kyutoki_m_result（form＝shown/hidden）→ kyutoki_lead_consent → kyutoki_lead_submit。
- 受付は kyutoki_leads（migrations/022）。status：new → asked → ready → offered → scheduled → done／closed。
- 集計：supabase/queries/kyutoki_b_funnel.sql。
