週次の集計：`supabase/queries/kyutoki_weekly_funnel.sql`

## 1. 公開前チェック（広告を出す前に全部）

      （空文字のあいだは送客ボタンが出ない。承認前に公開しても壊れない作り）
- [ ] 本番の `/kyutoki/oyu-ga-denai` で、東京・ガス給湯器・10年以上 → 結果に送客ボタンが出る
- [ ] 送客ボタンを押すと A8 のリンク経由で広告主サイトが開く
- [ ] GA4 のリアルタイムで `kyutoki_diag_start` → `kyutoki_diag_result` → `affiliate_click` が見える
- [ ] Supabase の `lp_event_logs` に `lp_id = 'kyutoki-oyu-ga-denai'` の行が入る
- [ ] A8 の「広告掲載URL管理」にページのURLを提出した

## 2. Google 広告の設定

- キャンペーン：`給湯器_ガス_東京神奈川_検索`（検索ネットワークのみ。ディスプレイは外す）
- 地域：東京都・神奈川県、「所在地」のみ
- 端末：スマホ中心（PC は入札 −30% から）
- 入札：上限CPC ¥109 の手動入札で開始 → 送客クリックが30件たまったら目標CPAへ
- コンバージョン：GA4 の `affiliate_click`（既存の設定を流用）。他LPと混ざるので、このキャンペーンの数字はキャンペーン単位で見る
- トラッキングテンプレート：
  `{lpurl}?utm_source=google&utm_medium=cpc&utm_campaign={campaignid}&utm_content={adgroupid}&utm_term={keyword}`
- 入稿用CSV（Google 広告エディタで読み込む）：キーワード・除外キーワード・レスポンシブ検索広告

## 3. 毎週の手順（月曜・15分）

1. Google 広告：費用、クリック、実CPC、送客コンバージョン（`affiliate_click`）
2. Supabase：`kyutoki_weekly_funnel.sql` の①〜④を実行
3. A8：今週の発生件数と金額（お湯が出ない.com／きゅっと／Cools）
4. 週次レビュー表に記入し、判定ラインと比べて「続ける・直す・止める」を1つ決める
5. 変えたことは下の変更履歴に1行で残す（何を・なぜ・いつ）

## 4. 判定ライン

| 指標 | 合格ライン | 下回ったら |
| --- | --- | --- |
| 実CPC | ¥109 以下 | 入札（低）が安いキーワードに絞る |
| 診断開始 → 送客クリック | 35% 以上 | 設問・文言を直す（直したら `VERDICT_VERSION` を上げる） |
| 送客クリック → A8 発生 | 16% 以上 | 30日の確定を待ってから判断 |
| 粗利率（A8 確定額 − 広告費）÷ A8 確定額 | 30% 以上 | 上限CPCを下げる |

止める条件：10日で送客クリック0件、または実CPCが ¥155 を超えて戻らない。
