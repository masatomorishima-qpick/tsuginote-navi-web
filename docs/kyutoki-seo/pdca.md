# 給湯器の記事（検索）の記録

目的・数字・決まりは docs/handover/kyutoki-seo.md、ページの設計は docs/kyutoki-seo/plan.md。

## 数字のつながり（記事ごとに同じ式）
**検索の表示 × クリック率 ＝ クリック → 記事を読む → B の受け皿へ（遷移率） ＝ B へ進んだ人**
- 表示：Search Console（ページで絞る）。動かすもの＝検索に登録されているか、受ける語と見出しが合っているか、順位
- クリック率：同（クリック÷表示）。動かすもの＝タイトルと説明文
- 遷移率：lp_event_logs（記事の lp_id の lp_internal_click で cta_id=/kyutoki/mitsumori）÷ 記事の lp_view（utm なし＝検索などの自然流入）。動かすもの＝入口の位置と言葉
- 配布物の押下：同（cta_id=/downloads/kyutoki-*）。遷移の手前の「役に立ったか」の数

## 記事ごとの関門（公開からの日数で見る。届かなければ、決めた打ち手を1つだけ打つ）
| 日 | 見る数字 | 合格の線 | 届かないときの打ち手（上から順に1つ） |
|---|---|---|---|
| 3日 | 検索への登録（URL 検査） | 登録済み | ①トップ・交換費用のページからの内部リンクを足し、登録を依頼し直す ②7日でも未登録なら「ページ」の報告で理由を見て、薄い・重複を直す |
| 14日 | 表示（直近7日）と、表示された検索語 | 目標の表示の2割（週あたり） | ①表示された検索語と見出しのずれを直す（受ける語をタイトル・最初の見出しに） ②表示0なら、受ける語の言い回しを Search Console の実際の語に合わせる |
| 28日 | 表示・順位・クリック率 | 表示が目標の5割、順位20以内 | ①順位が20より下：検索語のうち答えていない問いに節を足す ②表示はあるのにクリック率2%未満：タイトルと説明文を書き換える |
| クリック10件から | 遷移率・配布物の押下 | 遷移率15%以上 | ①Clarity でどこまで読まれたかを見て、入口を読まれている所まで上げる ②入口の言葉を、その記事の検索語に合わせる |
| 56日 | 目標の4つ | 4つとも目標の5割以上 | 5割未満が2つ以上：書き直すか、近いページに統合する（上限17ページは増やさない） |

運用の決まり（docs/operating-rules.md に合わせる）
- 1ページで同時に変えるのは1つだけ。変えたら版を上げ（version）、14日は次の手を打たない（検索の反映に時間がかかるため）。
- 毎朝：記事ごとの数字を下の表に1行ずつ足す（Search Console は2日遅れなので、2日前までの直近7日）。関門に当たった記事には、その日のうちに打ち手を1つ打つ（変更依頼まで）。
- 毎週月曜：記事ごとの目標との差と、打った手・結果をまとめる。
