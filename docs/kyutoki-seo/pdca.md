## 出口の決まり（オーナー指示 11/4 18:01「成果が最大化される形」「訪問者が迷う設計はやめる」）
- **1ページに出口は1つ。** その記事を検索する人の困りごとに一番合う紹介先だけを置く（本文の途中・末尾・スマホの画面下の固定ボタンは、同じ紹介先の同じボタン）。
- 交換を考えている人の記事（費用・見積もり・号数・住まい・機能・メーカー・エコジョーズ・急ぎ・支払い・年数など）→ **GAS-Q**（面談完了 5,280円・承認率67%。売り：他社より1円でも安く／見積もり無料／最短即日・当日の仮付け／後払い／10年保証）。
- 故障・エラー番号・急ぎの記事（修理で直る人・今日来てほしい人）→ **お湯が出ない.com**（修理も受ける。新規見積もり2,500円。東京・神奈川。A8 の1クリックの稼ぎ858円・確定95%＝11/4 確認）。11/4 22:40：P15 急ぎ もこちらに変更（GAS-Q はまだ押下0で稼ぎが分からない）。
- B の受け皿（/kyutoki/mitsumori）へは、記事からはつながない。B の業者が決まり、B の1クリックの価値（紹介料×依頼率×面談率）が GAS-Q の1クリックの価値を上回ったら、記事ごとに出口を入れ替える（入れ替えもその記事の出口は1つのまま）。判断はオーナー。**オーナー判断（11/4 19:24）：B のトライアル（ニーズ計測、11/10〜11/11 に判定）が終わってから検討する。それまで記事の出口は紹介先だけ。**

## 数字のつながり（記事ごとに同じ式。最後はお金）
**表示 × クリック率 ＝ クリック → 紹介先の押下 → 紹介先での成果（報酬）**
| 段 | 道具 | 動かすもの |
|---|---|---|
| 表示 | Search Console（ページで絞る） | 検索への登録、受ける語と見出し、順位 |
| クリック率 | 同 | タイトルと説明文 |
| 紹介先の押下 ÷ 自然流入の閲覧（**一番上の数字の手前**） | lp_event_logs（kyutoki_partner_click、位置ごと） | 紹介先の売りと、その記事の困りごとが合っているか。ボタンの位置と言葉 |
| 紹介先での成果・報酬（**一番上の数字**） | レントラックス・A8 の成果の報告（オーナーが週1回確かめる） | 紹介先の選び方 |
| 配布物の押下 | lp_event_logs | 役に立ったかの手前の数 |

注意（事実）：10/29〜11/1 に広告から記事型に来た約60人の紹介先の押下は0（docs/kyutoki-b/measure.md）。検索から来る人でも同じなら、記事を増やしても売上は0のまま。だから、お金の関門を早く置く（下の「関門」）。

## お金の見込み（60日目の1か月）
- 1クリックの報酬の見込み ＝ 紹介先の押下率10% × 成果率16%（docs/kyutoki-3c.md の置き）× 5,280円（GAS-Q の面談完了）＝ **約84円**。
- 60日目の目標（クリック約100回/月）なら、紹介先の押下 約10回 → 成果 約1.6件 → **報酬 約8,400円/月**。
- 事業として意味のある大きさ（例：月10万円）には、紹介先だけなら月1,200クリック程度が要る。60日の線は「そこへ伸びる見込みがあるか」を判断するための途中の数字で、60日の時点の売上そのものは小さい。
- 押下率・成果率は、まだ検索からの実測がない置きの数字。最初のお金の関門（閲覧100人）で実測に置き換える。

運用の決まり（docs/operating-rules.md に合わせる）
- 1ページで同時に変えるのは1つだけ。変えたら版を上げ（version）、14日は次の手を打たない（検索の反映に時間がかかるため）。
- 毎朝：記事ごとの数字を下の表に1行ずつ足す（Search Console は2日遅れなので、2日前までの直近7日）。関門に当たった記事には、その日のうちに打ち手を1つ打つ（変更依頼まで）。
- 毎週月曜：記事ごとの目標との差と、打った手・結果をまとめる。
