## 数字のつながり（記事ごとに同じ式。最後はお金）
**表示 × クリック率 ＝ クリック → 紹介先の押下 → 紹介先での成果（報酬）**
| 段 | 道具 | 動かすもの |
|---|---|---|
| 表示 | Search Console（ページで絞る） | 検索への登録、受ける語と見出し、順位 |
| クリック率 | 同 | タイトルと説明文 |
| 紹介先の押下 ÷ 自然流入の閲覧（**一番上の数字の手前**） | lp_event_logs（kyutoki_partner_click、位置ごと） | 紹介先の売りと、その記事の困りごとが合っているか。ボタンの位置と言葉 |
| 紹介先での成果・報酬（**一番上の数字**） | レントラックス・A8 の成果の報告（オーナーが週1回確かめる） | 紹介先の選び方 |
| 配布物の押下 | lp_event_logs | 役に立ったかの手前の数 |

## お金の見込み（60日目の1か月）
- 1クリックの報酬の見込み ＝ 紹介先の押下率10% × 成果率16%（docs/kyutoki-3c.md の置き）× 5,280円（GAS-Q の面談完了）＝ **約84円**。
- 60日目の目標（クリック約100回/月）なら、紹介先の押下 約10回 → 成果 約1.6件 → **報酬 約8,400円/月**。
- 事業として意味のある大きさ（例：月10万円）には、紹介先だけなら月1,200クリック程度が要る。60日の線は「そこへ伸びる見込みがあるか」を判断するための途中の数字で、60日の時点の売上そのものは小さい。
- 押下率・成果率は、まだ検索からの実測がない置きの数字。最初のお金の関門（閲覧100人）で実測に置き換える。
