## 1ページの作り方（毎回同じ）
1. 受ける言葉を words.tsv から抜き出し、Search Console に表示が出ている語があれば足す
2. 数字は一次情報だけ（東京ガス・メーカー公式・国の機関）。確かめた日を書く。数字は lib/kyutoki/haifu-data.json に足す
3. 見出しは名詞、文字を減らし、図・アイコン・表で見せる。最初の画面に「答え＋配布物」、下に B への入口
4. 型検査・スマホ幅の表示を確かめて変更依頼 → 取り込み後に本番を確認 → Search Console で登録を依頼 → 毎日の表に行を足す
