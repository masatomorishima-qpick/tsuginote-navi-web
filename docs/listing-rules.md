# 案件ごとの検索広告（リスティング）の決まり

A8 のプログラム詳細で確かめた内容。2026-10-29 にオーナーがスマホで確認。
新しい案件を足すときは、リンクを貼る前にここへ書き足す。

## 一覧

| ページ | 案件 | 検索広告 | 使えない言葉 |
|---|---|---|---|
| /kyutoki/oyu-ga-denai | お湯が出ない.com（株式会社GRACE） | 一部不可 | 商標・社名・サイト名・サービス名 |
| /kyutoki/oyu-ga-denai | きゅっと（株式会社GRACE） | 一部不可 | 商標・社名・サイト名・サービス名 |
| /check/scs | SUIKA VPN Team IP Service（株式会社MAJ Tech） | 一部不可 | 会社名・サービス名 |
| /check/scs | SiteLock | 一部不可 | 社名・サービス名を含むキーワード |

## 守ること
- 上の言葉はキーワードにも広告文にも入れない。表記ゆれ（カタカナ・英字・「ドットコム」など）も同じ扱い。
- 除外キーワードに入れて、指名検索に広告が出ないようにする。
  - 給湯器：com / ドットコム / どっとこむ / グレイス / grace / きゅっと / キュット / kyutto（docs/kyutoki-ads/negatives.csv）
  - 評価制度：suika / スイカ / maj / sitelock / サイトロック
- 広告であることの表示は、ファーストビューに置く（全ページ冒頭の「PR 当サイトは紹介料を受け取っています」）。表示がないと提携解除のおそれがある。

## 確認中
- 給湯器の「お湯が出ない」を含むキーワードは、サイト名「お湯が出ない.com」と重なる。一般的な症状の言葉として使ってよいか、A8 の問い合わせで広告主に確認する。返事が来るまで給湯器の広告は止めたままにする。
