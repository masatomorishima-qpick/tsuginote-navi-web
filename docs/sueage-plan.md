- 相続税の1,500は、群れの月間検索 約22万回の0.7%。1ページ目の下（10位前後）でクリック率1〜2%を、数語で取れれば届く数。
- 危ないところ：相続税の言葉は国税庁・税理士法人・大手の媒体が強い。このサイトは相続のひな形で 財産目録 18位 まで来ているが、相続税の大きな言葉で10位以内は未経験。だから「計算の道具」「早見表」「チェック表」など、配る型（保険の一覧表で4〜7位・クリック率5〜11%の実績）で取りに行く。
