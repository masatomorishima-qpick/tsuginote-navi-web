# 一番を取る場所の比較（製造業の図面・学校の教職員・医療）2026-11-04

3つの候補を「現場の声」「外からの要求」「お金を払った跡」「仕組みが効くか」で事実を集めて比べた。数字には出典、推測には「推測」。

## 結論

- **第一候補を「製造業の図面」から「学校（教育委員会）の教職員の校務」に変える。** 製造業は3つとも弱かった（中小の当事者の声が見つからない、取引先が生成AI を名指しで求める資料が無い、買った事例が無い）。学校は、国が教育委員会に「フィルタの設定やログの収集」と「個人情報を入力していないかの点検」を求め、令和9年度の概算要求で884億円（教職員が校務で安心して AI を使える環境づくりが中心）が計上され、端末に仕組みを強制的に入れられる。
- **3つに共通する大事な発見：お金は「入力を見張る道具」ではなく「安全に使える生成AI の環境」に流れている。** 学校は無料の Gemini for Education や契約済みの Microsoft の上に環境を作り、病院は院内の閉じた生成AI 環境に投資している（名古屋医療センターは削減効果を年5,000万円超と見込む）。入力の見張りだけを単体で買った跡は、どの業種でも見つからなかった。
- **だから売る物の形も変える。** 「その場で止める拡張機能」ではなく、**「公式に入れた生成AI の利用記録を自動で点検し、個人情報や機密の入力を見つけて、行政の点検項目に沿った報告書にする」**仕組みと、その周りの設定・ルール・研修。国の点検項目「プロンプトに個人情報を入力していないか」を人の目視から自動に置き換える。その場で止める製品は競合が多いが、公式の記録を読んで点検・報告する所は、日本語の学校向けでは見当たらない（未確認）。

## 学校で何を売るか（仮説）

| | 中身 |
|---|---|
| 顧客 | 市区町村の教育委員会（学校教育課・教育情報化の担当）。最初は大手の業者が深く入らない中規模の市町（推測） |
| 困りごと | 国の指針でログの収集と「個人情報を入力していないか」の点検を求められているが、点検を人の目で行う余力がない。教職員は「渡していいのか」が分からず使うのをためらう |
| 売る物 | ①設定：Gemini for Education／Microsoft の教育向けの安全設定（使える AI の限定、学習させない設定、記録の保存）②ルール：国の指針に沿った校務の利用ルールと教職員の確認テスト ③**点検の自動化：利用記録を毎月読み、個人情報の入力の疑いを見つけ、国の点検項目に沿った報告書にする** ④研修 |
| 買った後 | 教育委員会は点検の結果を報告書で示せる。教職員は「入れてはいけないもの」が分かり、安心して使える（実証校で「心理的な負担の軽減に不可欠」とされた点） |
| 差 | 国の点検項目に紐づいた自動の点検と報告書。入力の中身は自治体の環境の外に出さない作り |

## 失うもの・リスク

- 自治体の調達は年度単位で、令和9年度の予算はこれから決まる。最初の売上は2027年の春〜夏になる見込み（推測）で、12か月の線（2027年3月に月10万円）に間に合わない恐れがある。
- 実績の無い会社が入札に入るのは難しい。少額の随意契約、または教育の ICT の販売店と組む形から入る必要がある（推測）。
- Microsoft の情報保護（管理された Windows と Edge から外の生成AI への機密の送信を止める）と Google の管理機能が重なる。点検と報告書、日本語の学校向けの判断に集中して差を作る。
- 製造業は今は見送り。ただし図面の検知は技術の差になり得るので、学校で仕組みができた後の広げ先として残す。
