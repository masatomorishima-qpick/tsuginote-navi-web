# ChatGPT 広告の設計（生成AI利活用計画書の早見表）2026-11-05

ChatGPT 広告に詳しい専門家の視点で設計。他事業の検証（2026年10月）の総括と、オーナーの方針（話題の指定を作り込む、答えの続きと誤認させない、パソコンだけで試す）を反映。

## 1. 仕様（2026年11月時点。出典は末尾）
- 構成：キャンペーン（目的・予算・期間・国・端末）→ 広告グループ（話題の指定と入札）→ 広告（見出し・説明文・画像・飛び先）
- 話題の指定（コンテキストヒント）：完全一致ではなく「描写した会話・話題に近いか」の手がかり。1語ではなく、何を・誰に・いつ役立つかを書いた説明的な句で。1グループに1つの相手・用途だけ。除外の指定はできない（否定文は入れない）
- 会話別の成績は見られない（成績はグループ単位・広告単位）→ 検討の段階ごとにグループを分ける
- 文字数：見出し3〜50字（推奨16〜24字）、説明文100字以内（推奨32〜48字）。画像は正方形のみ（最大1200×1200）
- 表示されるのは、ログインしている成人の無料版と Go の利用者だけ
- 端末：Android アプリ／Android ウェブ／パソコンのウェブ／iOS アプリ／iOS ウェブから選ぶ
- 日予算は「7日間の平均」。1日の上限は日予算の2倍、7日の上限は7倍。週は日曜〜土曜。止めても最大24時間は配信と請求が続く
- 広告利用規約8.5条：OpenAI の名前・ロゴを宣伝物に使うのは書面の許可なしでは禁止。ChatGPT の画面・語り口に似せた広告は修正・削除の対象
- 計測：OpenAI の計測タグ。申込みの標準の名前は lead_created。飛び先の URL に oppref が自動で付く（転送で落とさない）。成果の反映は24〜48時間遅れることがある
- 飛び先の巡回（OAI-AdsBot）を許可しておく
- 未確認：ヒント1本の文字数上限、日本語のヒントの扱い、パソコン向けアプリがパソコンのウェブに入るか、手動入札の最低額

## 2. 出す前に直したこと（11/5 対応済み）
- 早見表ページの説明文（検索結果や共有で出る文）に Clarity の計測コードが入っていた → 正しい説明文に直した
- 早見表の ChatGPT の個人の行に Go がなかった → 「無料・Go・Plus・Pro」に直した（Go は個人で契約するプランで、学習の扱いは他の個人プランと同じ）
- 残り：OAI-AdsBot がサーバーの防御設定で止められていないかを、管理画面の飛び先チェックで確認する

## 3. 広告グループ（1つに絞る：11/5 オーナー判断）
予算が小さいので、依頼に一番近い「計画書の学習・履歴の欄を書いている最中の人」だけに出す。グループは1つ。

## 4. 話題の指定（公式ガイドに合わせて作り直し）
公式ガイド（Writing context hints for ChatGPT Ads）の要点：
- 話題の指定は「自社の商品・サービスについての追加の説明」。何を（機能・内容・価格）、誰に（どんな必要や状況の人に合うか）、いつ（どんな場面や判断で役立つか）を書く
- 広告文や飛び先ページだけでは伝わらない情報を足す。具体的に、商品と用途の本当のつながりを、正確に書く
- キーワードの羅列ではなく、1つの考えに絞った自然な句にする（1本で3つ全部を満たさなくてよい）
- 「この相手に届けたい」というだけでは関連性にならない。配信の指示（地域・除外など）は書かない
- 同じ商品・テーマ・顧客の必要でまとめる。言い方や飛び先が違うならグループを分ける

前の案は「〜している技術者」と相手の姿を描く書き方が中心だったため、商品の中身・役立つ相手・場面を書く形に直した。

### 何を（4本）
1. 国土交通省の生成AI利活用計画書のうち、発注者確認チェックリスト6-3・6-4・7-3・7-4（学習に使われない措置と利用履歴の保存の根拠）に絞った記入例
2. ChatGPT・Copilot・Gemini・Claude の契約プランごとに、学習と履歴の根拠を示せるかを公式資料の出典つきで○△×にまとめた早見表
3. 使っている生成AIのサービス名と契約プランを送ると、その契約に合わせた記入例と根拠資料を3日以内に無料で返す
4. 個人で契約した無料版や安いプランを業務に使っている場合に、計画書の学習と履歴の欄で示せることと示せないことの整理

### 誰に（2本）
5. 国土交通省直轄の測量・土木の建設コンサルタント・地質調査の業務を受注した中小企業の管理技術者
6. 社内に情報システムの担当がおらず、生成AIの契約内容と計画書に書ける根拠を自分で確かめなければならない技術者

### いつ（4本）
7. 業務計画書と一緒に出す生成AI利活用計画書で、学習と履歴の欄の根拠が書けずに手が止まったとき
8. 発注者から、入力した情報が学習に使われない根拠や利用履歴の保存方法を示すよう求められたとき
9. 報告書のとりまとめに生成AIを使うことを決め、計画書のひな型を埋め始めたとき
10. 根拠を示せないと分かり、上位プランへの切り替え・社内規程で補う・対象業務では使わない、のどれにするか決めるとき

## 5. 広告文と画像（公式ガイド「Creative enhancements」を踏まえて）
公式ガイドの要点：
- 「クリエイティブの強化」は 2026/10/30 から新規・既存のキャンペーンで初期設定がオン。会話の文脈・広告・飛び先ページの内容をもとに、見出し・説明文の書き換え、翻訳、画像の大きさの調整、飛び先 URL の変更を行う
- オンだと、作られた文面を事前に確認・承認せずに配信される（すべての文面の下見はできない）
- 管理画面の「Manage settings」でキャンペーンごとにオフにできる。キャンペーンの設定がアカウントの初期設定より優先
- 広告主がやること：広告と飛び先ページの情報を最新に保つ、何を提供し、なぜ役立つかを明確で具体的に書く、広告ポリシーに沿う

判断：**この試験ではオフにする。**
- 書き換えで「受注者向け」「外部ページ」の言葉が消えると、答えの続きと誤認されやすくなる（前回の0秒離脱の対策が崩れる）
- 飛び先 URL を変えられると、早見表ページ以外に飛ばされ、経路の印も落ちて依頼率が測れなくなる
- 下見できない文面で、国土交通省との関係を思わせる表現や、早見表にない中身が出るおそれがある（前回は自社にない機能が自動で入った）
- 2週目以降に、成績が安定したら「オン」との比較を検討する

広告（2本。違いは見出しの切り口）
| | 見出し | 説明文 |
|---|---|---|
| 1 | 生成AI利活用計画書の記入例 | 建設コンサル・測量・地質の受注者向け。学習と履歴の欄（6-3〜7-4）の記入例と根拠の早見表を外部ページで無料公開 |
| 2 | 計画書の学習・履歴欄 根拠の早見表 | 契約プランごとに示せる根拠を、公式資料の出典つきで整理。建設コンサル・測量・地質の受注者向けの外部ページ（無料） |

決まり：製品名・OpenAI の名前は広告文と画像に入れない。「公式」「国交省推奨」は使わない。見出しは名詞で終え、語りかけ・問いかけ・「回答」「続きはこちら」は使わない。

画像（1200×1200、1枚）：白地に紺の文字。上「生成AI利活用計画書」、下「学習・履歴の欄の記入例」。中央に書類の絵と「6-3 6-4 7-3 7-4」の札。下の帯に小さく「建設コンサル・測量・地質の受注者向け」。ChatGPT の緑や黒い画面、吹き出し、入力欄、各社のロゴは使わない。

## 6. 配信の設定
| 項目 | 設定 |
|---|---|
| 目的 | クリック課金 |
| 入札 | 手動・上限450円（前回の管理画面で「強」と出た額。払ってよい上限670円の内側）。3日目に表示が累計300未満なら600円に上げる |
| 予算 | 日予算2,500円（1日最大5,000円、7日で最大17,500円） |
| 期間 | 世界標準時で 11/8（日）0:00〜11/14（土）23:59（日本時間 11/8 9:00〜11/15 8:59） |
| 端末 | パソコンのウェブのみ |
| 地域 | 日本を明示して指定 |
| クリエイティブの強化 | オフ（キャンペーン単位） |

## 7. 計測
- 飛び先：https://blueadventures.jp/ai-plan-hayamihyo/?utm_source=chatgpt&utm_medium=cpc&utm_campaign=ai-plan&utm_content=（ad1/ad2）&from=gpt
- OpenAI の計測タグ：早見表ページとお礼ページに基本のコードを置き、お礼ページでだけ lead_created を1回送る（フォーム送信の直前に閲覧中だけ残る印を置き、印があるときだけ送って消す。再読み込みでの二重計上を防ぐ）
- Clarity：お礼ページで送信の印を記録し、広告別に滞在・読み進み・フォーム到達・送信を見る
- フォームの「流入元（自動入力）」で、依頼ごとの経路を確認する
- プライバシーポリシーに「アクセス解析・広告の計測」（Google アナリティクス、Microsoft Clarity、Google 広告、OpenAI）を足す（オーナー確認のうえ保存）

## 8. 毎日見る数字と判断
目標：1週間で依頼2件（1件あたり8,750円以下）、最低1件。1クリック450円前後なら約35クリックで依頼率5.7%が必要。

毎日（日本時間9時すぎ）：グループ別・広告別の表示・クリック・クリック率・1クリック単価・費用・端末／Clarity の訪問・10秒以上の滞在・表まで読んだ割合・フォーム到達・送信／lead_created とフォームの回答数／管理画面のクリックと Clarity の訪問の比（8割未満なら計測漏れを疑う）

3日目（11/11 9時）
| 状態 | 打ち手 |
|---|---|
| 表示が累計300未満 | 上限を600円に。足りなければ、何を・誰に・いつの形で話題の指定を5本足す |
| 表示500以上でクリック率0.7%未満 | 広告文と画像を差し替え |
| クリック15以上で10秒以上の滞在が30%未満 | Clarity の録画で、最初の画面と広告が合っているかを見る |
| フォーム到達20%以上で送信0 | フォームを直す |

7日目（11/15 9時）
| 状態 | 判断 |
|---|---|
| 依頼2件以上 | もう1週。次は「学習・履歴の根拠を調べている人」のグループを足すか、クリエイティブの強化オンとの比較を検討 |
| 依頼1件 | 直してもう1週 |
| 依頼0・クリック30以上・フォーム到達15%以上 | フォームを直してから1週 |
| 依頼0・クリック30以上・フォーム到達15%未満 | 広告を止めて早見表ページを直す |
| 依頼0・クリック20未満 | この媒体では会話の量が足りない。検索広告に予算を移すか判断 |
