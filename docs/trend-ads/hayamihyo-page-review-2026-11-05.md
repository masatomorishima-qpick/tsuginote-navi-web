# 早見表ページの見直し（マーケターと営業の検討）2026-11-05

マーケター（法人向け集客・検索）と営業（建設・官公庁関連の中小企業への法人営業）に、それぞれ独立してページを批判してもらい、すり合わせた。どちらもパソコン幅とスマホ幅で画面を確認済み。

## 結論
資料としての価値はある（自社の契約の位置がすぐ分かる、確認日・出典がある）。ただし今のままでは「スマホで大事な列が見えない」「誰が何のために作ったか分からない」「返信すると何が起きるか分からない」の3つで、満足度も返信も落ちる。直す順は次のとおり。

## 2人が一致した問題（重い順）
1. スマホで表の右半分（利用履歴の保存の印・判定の理由）が見えない。学習の列だけ見て「うちは大丈夫」と誤解される。
2. 作り手の正体と動機が分からない。社名だけでは何の会社か伝わらず、「関係ありません」も最下部の小さな字。
3. 返信の入口があいまい。番号を覚えている人はいない。返すと何が届くか、費用、返事までの日数、電話が来ないかが分からない。
4. 出口が3つ（上の「お問い合わせ」、真ん中のメール、下の「お問い合わせ」）。
5. △・×だったときに次に何をすればよいかが、小さな灰色の注に埋もれている。
6. 一番欲しい「そのまま写せる記入例」がない。

## 片方だけが挙げた問題
- マーケター：判定の食い違い。個人契約の行は印が△なのに理由が「根拠を示せません」。欄外では「7-4は社内規程で補える」と書きつつ表は×。専門家に「雑だ」と思われる。
- マーケター：国内サービス2行は両方「確認が必要」で役に立たず、提供元から苦情の恐れ。確認が済むまで外す。
- マーケター：検索から来る人向けに、計画書の基本（対象業務・誰が・いつ・様式）がない。
- マーケター：「Vault」「Compliance API」「実効性」などの言葉が硬い。
- 営業：出典が関東地方整備局の資料で、全国で同じか分からない。「規定」と「規程」の表記ゆれ。

## 直し方
| 順 | 直す箇所 | 中身 |
|---|---|---|
| 1 | 最初の画面 | 3枚の札をやめ、結論の帯3段に置き換える：「個人で契約 → 学習△・保存×」「法人の基本プラン → 学習○・保存△/×」「法人の上位プラン → 両方○」。5秒で自社の位置が分かる |
| 2 | 作り手の1行 | 結論の帯の下に「BlueAdventures合同会社（横浜）が、国土交通省の通知と各社の公開資料を突き合わせて作成しました。国土交通省・各提供元とは関係ありません。誤りがあればご指摘ください。」 |
| 3 | スマホの表 | 600px以下ではサービスごとのカード（学習の印・保存の印・理由1行）に切り替える |
| 4 | 判定の整合 | 個人契約の理由を「各社員が学習を止める設定をし、その画面を根拠にする必要があります」に直し△の根拠と合わせる。凡例の×を「サービスの機能だけでは記載が難しい（社内規程で補う）」にする |
| 5 | 基本情報 | 小さな4枠：対象（測量・土木の建設コンサルタント・地質調査で、生成AIで成果をまとめる業務）／出す人（受注者）／出し方（業務計画書と一緒に。様式は発注者が電子データで示す）／始まり（2026年7月29日の本省通知以降の業務）。本省通知は全国の地方整備局あてと明記 |
| 6 | △・×のときの対処 | 見出しつきで独立。図で3つ：「上位の契約に切り替える」「社内規程で補い、運用の記録を残す」「計画書の対象業務では使わない」 |
| 7 | 記入例 | 6-4と7-4の1文の記入例を空欄つきで1つずつ載せる（続きはメールで） |
| 8 | 出口を1つに | 上下の「お問い合わせ」を外す。見出し「サービス別の記入例をお送りします（無料）」、ボタン「サービス名を書いて受け取る」。メールを開くと本文に「利用中のサービスと契約：／迷っている項目（任意）：」が入っている。ボタンの下に宛先のメールアドレスを文字でも表示。安心材料（社名なしで可・電話はしない・何営業日以内に返す）はオーナーが守れる範囲だけ書く |
| 9 | 削る・言い換え | 国内サービス2行を外す。「Vault」→「管理画面の保存機能（Vault）」、「実効性」→「規程どおりに運用されているか」。出典は資料名のリンクにして折りたたむ。「規定」を「規程」にそろえる。メールの件名を「計画書の記入例の依頼」に |

## 数字で見ること
- メール送信先のうち、ページを開いた割合（ページの閲覧数÷送信数）
- ページを開いた人のうち、記入例を依頼した割合（依頼メール数÷閲覧数）。目標：送信約45件・閲覧15件・依頼3件（推測）
- 依頼の中身（サービス名・項目）を聞き取りの材料にする

## オーナーに決めていただくこと
1. 返信の約束：「社名なしで可」「電話はしない」「〇営業日以内に返す」のどれを書くか（日数は守れる範囲で）
2. 作り手の1行に、会社が何をしているか（例：「生成AIの安全な使い方の整理と導入を支援する」）まで書いてよいか
