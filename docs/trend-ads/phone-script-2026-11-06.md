# 電話の台本と想定問答（営業とマーケターの視点で整理）

## 0. 前の台本から変えたところ
| 前の台本 | 変更後 | 理由 |
|---|---|---|
| 社名のすぐあとに「関東地方整備局の『〜業務』を…」 | 先に「民間の会社です」と言い、業務名は「御社が受注された〜」と言う | 整備局の名前が先に出ると、発注者からの電話と思い込まれやすい |
| 「1分だけ」 | 「3分ほど」 | 4問聞くと1分では終わらない。約束を超えると信用を失う |
| 最初の質問が「この業務で生成AIをお使いですか」 | 先に会社全体で聞き、そのあと国の業務で聞く | いきなり業務で聞くと、調べられているように感じて身構える |
| 使わない理由を選択肢で聞く | まず自由に答えてもらい、詰まったときだけ例を出す | 選択肢を先に並べると答えが寄る |
| 担当が不在のときの次の手がない | 生成AIの扱いを決めている方（総務・情報システム）にも当たる | 測量の技術者は現場に出ていることが多い |

## 1. 台本

### 受付（最初の15秒）
> 「お忙しいところ恐れ入ります。横浜の、ブルーアドベンチャーズ合同会社の森嶋と申します。生成AIの使い方を調べている民間の会社です。御社が受注された、関東地方整備局の『**（業務名）**』のご担当の技術者の方に、3分ほどお話を伺いたくお電話いたしました。管理技術者の方はいらっしゃいますでしょうか。」

**「ご用件は？」と聞かれたら**
> 「国の測量や設計の業務で生成AIを使う場合に、今年から新しく出すことになった書類があります。その件で、各社さんの実情を伺っています。物を売るお電話ではありません。」

**担当が分からない／業務名で通じないとき**
> 「もしお分かりにならなければ、社内で生成AIの扱いを決めていらっしゃる方、たとえば総務や情報システムのご担当の方でも構いません。」

**不在のとき**
> 「承知しました。何時ごろお戻りでしょうか。……では、その頃に改めてお電話いたします。折り返しはお気遣いなく。差し支えなければ、ご担当の方のお名字だけ伺えますか。」
（名字を断られたら「業務名でお取り次ぎいただければ十分です」と言ってすぐに引く。かけ直しは2回まで）

### 本人（最初の20秒）
> 「お電話を代わっていただき、ありがとうございます。ブルーアドベンチャーズ合同会社の森嶋と申します。最初にお伝えしますと、国や整備局とは関係のない、横浜の民間の会社です。
> 整備局の公表資料で『（業務名）』のご受注を拝見しました。7月に国土交通省から通知が出た『生成AI利活用計画書』について、各社さんの実情を伺っています。物を売るお電話ではありません。3分ほどよろしいでしょうか。」

- 断られたら：「失礼いたしました。お時間をいただき、ありがとうございました。」で終える。
- 「今は無理」と言われたら：「ご都合のよい日時を伺えれば、そのときにかけ直します。」

### 質問

**問1　使っているか（まず会社全体、次に国の業務）**
> 「使っている会社も使っていない会社もありますので、良い悪いということではなく伺います。御社では、報告書や資料づくりなどで、生成AIはお使いになっていますか。」

#### 分岐A：使っている
> 「差し支えなければ、どのサービスでしょうか。会社で契約されたものですか、それとも皆さん個人で使われていますか。」
> 「国の業務、たとえば今回の業務でもお使いですか。」
→ 問2へ

**問2　計画書**
> 「生成AI利活用計画書は、もう出されましたか。それとも、発注者から出すように言われていますか。」
- 出した、または言われた → 問3へ
- 何も言われていない → 「そうでしたか。」とだけ返して問4へ（対象かどうかの意見は言わない）
- 計画書を知らなかった → 「7月29日の通知で、直轄の測量・設計・地質の業務で、生成AIを使って成果をまとめる場合に、業務計画書と一緒に出す書類です。今回の業務が対象かは発注者のご判断なので、私からは申し上げられません。」と伝えて問4へ

**問3　根拠を聞かれたか**
> 「出されたとき（言われたとき）に、発注者から、入力した情報が学習に使われない根拠や、利用履歴の保存方法について、確認や質問はありましたか。」
- あった → 「どんなことを聞かれましたか。」（言葉をそのまま書き留める）
- 時間がなさそうなら問3は飛ばして問4へ

**問4　送付の了承**
> 「ありがとうございます。ChatGPT・Copilot・Gemini・Claude について、契約のプランごとに、計画書の学習と履歴の欄に何を書けるかを、公式資料の出典つきでまとめた早見表があります。メールでお送りしてもよろしいでしょうか。」
- 了承なら：「お送り先は、代表のアドレスでも、ご担当の方のアドレスでも、ご都合のよい方で結構です。」→ アドレスを1文字ずつ復唱して確かめる

#### 分岐B：使っていない
> 「承知しました。差し支えなければ、使っていらっしゃらない理由を伺えますか。」
（詰まったときだけ「たとえば社内の決まりですとか、情報の扱いが心配ですとか」）
> 「発注者から、生成AIを使うかどうかを聞かれたことはありますか。」
> 「今後お使いになるときのご参考に、早見表をメールでお送りしてもよろしいでしょうか。ご不要でしたら、ここで失礼いたします。」

#### 分岐C：検討中
> 「どのあたりで迷われていますか。」
> 「候補のサービスはありますか。」
> 「検討の中で、計画書のことは話に出ていますか。発注者から何か言われていますか。」
→ 問4へ（「サービス選びの比較にお使いいただけると思います」と一言添える）

#### 分岐D：本人も社内の状況を知らない
> 「社内で生成AIの扱いを決めているのは、どちらの部署でしょうか。」
→ 問4へ（宛先はその部署か代表のアドレス）

### 締め
> 「本日中に、件名『生成AI利活用計画書 早見表のお送り（BlueAdventures 森嶋）』でお送りします。お忙しいところ、ありがとうございました。失礼いたします。」
（相手が切るのを待ってから切る）

## 3. 電話のあと

### 記録（チャットに貼ってもらえれば記録表に入れます）
```
日時／会社／業務名（契約日）／取り次ぎ：本人・別部署・不在（戻り時刻）・断り（言葉）／話した方：部署・役職／通話時間

　使わない理由・迷っている点（言葉どおり）：
問2 計画書：出した・言われた（未提出）・言われていない・知らなかった
問3 根拠：聞かれた（内容を言葉どおり）・聞かれていない・未確認
問4 送付：了承（宛先：代表・担当・部署）・不要
社内の決まり：ある・作成中・ない・不明
ひとこと（いちばん印象に残った言葉をそのまま）：
次の行動：かけ直し（日時）・なし
```

- 個人のアドレスを教えてもらっても、記録には「担当」とだけ書く。

## 4. よくある失敗と避け方
1. **発注者や国の関係者だと誤解される**：社名のあとすぐ「民間の会社です」と言い、業務名は「御社が受注された〜」の形で。本人にも最初の20秒で繰り返す。
2. **質問が調査や監査のように聞こえる**：会社全体から国の業務へと順に聞き、「良い悪いではなく」と添える。出す・出さないの是非には触れない。
3. **分からないことを言い切る**：「この業務も対象です」「このプランなら大丈夫です」は言わない。「対象かは発注者のご判断です」「最終的には公式資料でご確認ください」の2つで返す。
4. **説明しすぎて売り込みになる**：早見表の中身は「メールでお送りします」で止める。断られたらその場で引く。
5. **答えを誘導・言い換えて記録する**：選択肢を先に出さない。「つまり〇〇ですね」とまとめない。電話を切った直後に相手の言葉どおりに書く。
