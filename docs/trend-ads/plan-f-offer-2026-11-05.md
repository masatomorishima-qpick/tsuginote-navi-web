# 売る物の具体化（起業家・営業・マーケターの検討）2026-11-05

## 3人が一致したこと
- 無料の記入例は「書き方」。有料は「御社が本当にその状態になっている証拠」をそろえる作業（設定画面の写し、承認済みの規程、約款の該当条文、再委託先の確認書）。記入例では作れない。
- この作業に土木の専門知識は要らない（契約・設定・規程・根拠の話）。
- 「業務別の指示文で時短」は土木の知識がないと質を保証できない → 売る物から外す。
- 一番の競合は他社の無料配布ではなく、お客さまが「この業務では生成AIを使わない」と決めること（通知に罰則も成績評定への影響も書かれていない）。
- 最初の3社は無料でよい。条件つき。

## 単発：「計画書の根拠をそろえる」9.8万円（社員40人の例、2週間・当社作業約12時間）
流れ：1日目 聞き取り60分 → 2〜5日目 法人契約への移行と管理画面の設定（画面共有で一緒に）→ 6〜10日目 書類づくり → 最終日 説明60分
納品物
1. 利用実態一覧（誰が何の契約で使っているか）
2. 契約プラン選定書（候補3つの比較と選定理由）
3. 管理画面の設定記録（学習させない設定・履歴の保存。画面の写しと日付つき）
4. 生成AI利用規程（入力してよい情報、履歴の保存期間と削除、確認体制。代表の承認欄つき）
5. 根拠資料集（約款の該当条文と出典）
6. 再委託先への確認依頼書と回答様式
7. 計画書の記入対応表（自社の内容をどの欄に書くか。記入はお客さま）

## 継続：月額ではなく「業務ごと」2万円（営業の案を採用）
受注した業務ごとに：その業務の範囲に合わせた記入対応表の更新／再委託先の確認書の回収と一覧／発注者から直しを求められたときの修正文の案（3日以内）／各社の規約が変わっていれば根拠資料の差し替え
理由：時短に月3万円は効果の数字を見るまで払われない。業務ごとなら受注と連動し、業務の費用に計上できる。件数の多い会社にだけ後から年間契約を出す。

## 無料の記入例があるのに払うのは誰か
- 足りる会社：情報担当がいる、法人契約と規程が既にある、使わないと決める
- 足りない（払う）会社：社員10〜50人で情報担当がいない、社員が無料版を各自で使っている、直轄業務を年に数件以上受ける、再委託を出す／受ける
- 直轄業務を受ける中小に声をかけて15〜20社に1社（営業の推測）

## 最初の3社（無料）の条件
1. 国の直轄業務の受注実績があり、生成AIを使う（使う予定の）会社に限る
2. 発注者の反応（直しを求められたか、指摘の文）を共有してもらう
3. 事例として載せる許可（業種と規模まで）
4. 作業時間と詰まった箇所の記録に協力してもらう（1社12時間を超えたら価格を見直す）
5. 次の業務からの有料価格（業務ごと2万円）を最初に合意する
6. 同業か再委託先を2社紹介してもらう
組み方：「元請1社とその再委託先」で組むと紹介がつながる。記入と提出はお客さまという責任範囲を書面にする。

## 成功の目安（3社で）
- 3社中2社が発注者の直しなしで受理される
- 1社以上が次の業務から有料で依頼する
- 紹介が2社以上つながる
届かなければ、売る物を「再委託先の回答回収と規約変更の追跡」を年額数万円で多くの会社に売る形に変える（起業家の切り替え案）。

## 残る大きな危うさ
- 通知の対象は国の発注業務だけ。地方の20〜80人の会社は県・市町村の仕事が中心で、需要の引き金が限られる。市場の大きさの上限が低い。
- 発注者が根拠をどこまで厳しく見るかは未確認。ゆるければ無料の記入例で足りてしまう。最初の3社の「直しの有無」が続けるかどうかの一番の指標。
- 売上の上限：単発9.8万円＋業務ごと2万円の形で月100万円には、単発6件＋業務20件が要る。届かない恐れがある。
