# 事業の要点（1枚）2026-11-05

起業家とマーケターの検討結果と、払う動機の点検をもとに要点だけにまとめた。

## 何の事業か
建設コンサルタント・測量・地質調査の会社に、国土交通省の計画書に通る形で生成AIを入れ、報告書づくりの時間を減らす。規制対応で入り、時短で続けてもらう。

## 顧客
社員20〜80人、国の直轄業務を年数件受ける地方の会社。技術者が生成AIを個人で使い始め、技術部長か総務課長が計画書の根拠で止まっている。

## 売る物
| 段 | 中身 | 価格（税別） |
|---|---|---|
| 無料 | 早見表と記入例。3日以内（実際は当日）に返す | 0円 |
| 単発：安全導入 | 契約プランの選定、管理画面の設定、運用の決まり、計画書の根拠一式（記入はお客さま） | 9.8万円 |
| 継続：時短の伴走 | 業務別の指示文とひな形づくり、月1回の使い方相談、規約・機能変更の反映、再委託先への根拠依頼の代行、毎月の短縮時間の報告 | 月3万円 |

価格の根拠（仮）：技術者5人が月10時間ずつ短縮できれば、時給5,000円換算で月25万円分。月3万円はその1割強。

## どこよりも満足してもらう方法
1. 速さ：問い合わせは当日中に返す（問い合わせ対応AIのひな形）
2. 業界の言葉：計画書の項目番号と発注者の確認の目線で話す
3. 1社ごと：その会社の業務に合わせた指示文とひな形を渡す
4. 成果を数字で：毎月「何時間減ったか」を報告する

## 売上の道筋（仮）
2027/3 月10万（単発1件）→ 6月 月30万（単発2件＋継続3社）→ 9月 月100万（単発5件＋継続17社）

## 11/20の判定
- 記入例の依頼が案内の7％以上
- 「生成AIでこの作業を何時間減らしたい」が3件以上（時短の動機）
- 「9.8万円なら頼む」が2社以上
どれかが届かなければ、単発のみの小さな事業として扱い、柱の候補から外す。

## 我々のリスク
1. 土木の専門知識がない：時短の伴走で業務の中身に入れない。対策：技術士などの協力者と組む（note で計画書の見本を出している技術士が最初の候補）
2. 「使わない」と書けば済む：需要そのものが消える。対策：電話の最初の質問で使っている会社だけに絞る
3. 本業との両立：相手は平日の昼に動く。対策：15分の確認を昼休みと夕方の予約制に。継続は月20社前後が上限
4. 実績ゼロの信用：対策：最初の3社は半額で事例掲載の承諾をもらう。適格請求書の登録
5. 法律の線：計画書を有料で作ると行政書士法に触れる恐れ。対策：記入はお客さま、当社は設定と根拠まで
6. 競合と提供元：記入例を無料で配る会社が既にあり、提供元が自前で根拠資料を出す恐れ。対策：速さと1社ごとの時短で差をつける
7. 市場の上限：直轄業務の受注者の数に限りがある。対策：同じ様式が自治体・他省庁に広がるのを見張って横展開
