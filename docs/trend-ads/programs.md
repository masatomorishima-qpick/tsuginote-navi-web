# 調べた案件の一覧（トレンド施策用）

トレンドが出たら、まずここと照らす。新しく調べた案件は書き足す。
「1クリックの報酬実績」は A8 の表示（過去の平均）。空欄は実績なし。

## 判断の形（2026-10-30 改訂。オーナーの指摘で、キーワードプランナーの数字を合否に使うのをやめた）

この施策の狙いは「キーワードプランナーにまだ出てこない新しい言葉を、誰より先に押さえる」こと。
過去の検索数や入札の相場は、新しい言葉には存在しない。だから合否には使わず、規模の参考にだけ使う。

提案する条件（4つ全部）
1. 季節では説明できない動きがあり、言葉が新しい（プランナーに出ない、または前年にない）
2. 検索した人の次の行動が、申し込み・契約・見積もり・無料体験の登録である（品物を買うだけなら弱い）
3. 申し込み型の紹介先がある（固定報酬。提携済みか即時提携。検索広告が可）
4. 24〜72時間で出せる（診断・計算・比較のどれかの型に収まる）

通ったものは、試験で測る（判断は試験の数字でする）
- 広告費1万円、日予算1,000円、7日間。どちらか早い方で止める
- 入札の上限は「報酬 × 見込みの申込率 × 0.4」から始める（例：報酬5,000円 × 2% × 0.4 = 40円）。表示が出なければ上げる
- 合格：送客率15%以上、実際の単価が上限の1.5倍以内、成果の発生1件以上

扱わないもの：災害・事故への便乗、特定の人物の騒動、退職代行・医療脱毛、仮想通貨。人の死去が起点の話題は、広告文と見出しに名前や死去を使わない前提でだけ検討する。

拾う粒度：毎朝500件規模。Googleの急上昇は全ページ、エックスは全ての欄、ヤフーは分野別の順位、官公庁は6省庁＋意見募集、Security NEXT、NHK、日経、PR TIMES。全件を docs/trend-ads/scan/<日付>.md に残す。
