# 計算係（キャラクター）の設計と Gemini への指示文（2026-11-06）

## 設計
- 姿：卓上の電卓の形をした小さな体。画面の部分が顔（点の目と小さな口）。短い手足。冬なので黄色のマフラー。
- 色：紺（#101830）と黄（#FFCC00）。プロフィール写真と動画の数字の画面に合わせる。
- 絵の調子：平面のイラスト、太い線。実在の人や物に見せない（AI 生成のラベルの中心の対象を避け、作り物の実測と誤解されないため）。
- 性格：計算が好き。我慢の節約が嫌い。口ぐせ「計算しました」。
- 既存のキャラクターに似せない。似ていると指摘されたら作り直す。

## 手順1：基本の絵（Gemini の「画像」）
```
オリジナルのマスコットキャラクターを1体描いてください。
・卓上の電卓の形をした小さなキャラクター。体は紺色、ボタンは黄色。
・電卓の画面の部分が顔。白い画面に、黒い点の目と小さな口。
・短い手と足。首に黄色のニットのマフラー。
・平面のイラスト、太めの黒い線、影は少なめ。背景は無地の濃い紺色。
・正面を向いて立ち、片手を軽く上げている。
・文字やロゴは入れない。既存のキャラクターに似せない。
縦長（9:16）、キャラクターは画面の下半分に置き、上半分は空けておく。
```

## 手順2：表情の5種類（手順1の絵を添付して、1つずつ）
```
添付のキャラクターと同じ姿・同じ色・同じ線の太さで、次の表情と動きを描いてください。背景は無地の濃い紺色。文字は入れない。縦長（9:16）、キャラクターは画面の下半分、上半分は空ける。
表情：〔ここを差し替える〕
```
差し替える表情：
1. 電気代の請求の紙を両手で持って、目を丸くして驚いている
2. 片手を頬に当てて考えている
3. 小さなそろばんをはじいて計算している
4. 見る人の方を指さして、にっこりしている
5. 両手を上げて「できた」と喜んでいる

## 手順3：動き（Gemini の「動画」）
設定：縦向き、モデルは Pro、手順2の絵を1枚添付。
```
添付のキャラクターを、同じ姿のまま8秒だけ動かしてください。
動き：〔ここを差し替える〕
・カメラは固定。背景は無地の濃い紺色のまま。
・セリフは入れない。小さな効果音だけ。
・文字やロゴを画面に出さない。
・キャラクターは画面の下半分、上半分は空けたまま。
```
差し替える動き（1本目に使う3つ）：
- 驚き：請求の紙を見て、びくっと跳ねて目を丸くする
- 計算：そろばんを素早くはじき、最後にうなずく
- 呼びかけ：こちらを指さしてから、手招きする
