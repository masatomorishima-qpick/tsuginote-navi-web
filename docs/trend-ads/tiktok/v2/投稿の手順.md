# 新しい型の1本目「先月の電気代、いくらでした？」の投稿の手順

投稿先：@denkidai_keisan。**投稿の前に、画面の上の名前が「電気代の計算係」か確かめる。**

1. 01_問いかけ.mp4 を選ぶ（22秒。Gemini の効果音入り）。
2. 「テキスト」で下の読み上げの文を場面ごとに入れ、「読み上げ」をオンにする。声は毎回同じものを選ぶ。読み上げに使った文字は画面の外に動かすか透明にして、画面の文字と重ねない。
3. 説明文に下の文をそのまま貼る。
4. **「AI生成コンテンツ」をオンにする**（キャラクターと動きを AI で作っているため）。
5. 投稿の時間：朝7時台か夜21時台。
6. 投稿後、コメントが来たら、部屋の広さ・器具・時間を書いてくれた人に、こちらで計算した返信の動画を作る（コメントを写して送ってください）。

読み上げ（場面ごと）：
1. 先月の電気代、いくらでした？
2. 一人暮らしのエアコン暖房、1日6時間で、月700円から7800円。
3. 同じエアコンでも約11倍の差。差は使い方と部屋で決まります。
4. あなたの部屋の広さと暖房、コメントで教えて。計算して返します。計算係でした。

説明文：
```
同じエアコンでも、使い方で月700円〜7,800円（約11倍）。あなたの部屋の広さ・暖房器具・1日に使う時間をコメントで教えてください。計算して動画で返します。
前提：パナソニック CS-283DFL（8〜12畳）の最小125W〜最大1,390W、電気の単価31円/kWh（全国家庭電気製品公正取引協議会の目安）、1日6時間×30日。消費電力の出どころ：セレクトラ（2026/10/30）。キャラクターと動きはAIで作成しています。
#電気代 #一人暮らし #暖房 #エアコン #節約
```
