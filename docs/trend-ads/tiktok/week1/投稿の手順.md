# 1週目の投稿の手順（1〜3本目）

各動画は音声なし。TikTok の編集画面で次の順に付ける。
1. 動画を選ぶ → 「テキスト」で下の読み上げの文を場面ごとに入れ、「読み上げ」をオンにする（声は毎回同じものを選ぶ）。文字は画面の外に置くか透明にして、画面の数字と重ねない。
2. 音楽は小さく（任意）。
3. 説明文に下の文をそのまま貼る。
4. 投稿の設定：「AI生成コンテンツ」はオフでよい（人物や実在の場所を作っていないため）。商品の紹介は入れていない。
5. 投稿の時間の案：朝7時台と夜21時台。

## 01：オイルヒーター、1時間いくら？

読み上げ（場面ごと）：
1. オイルヒーターの最大は、1時間46.5円。
2. エアコンの標準の約2.3倍です。
3. でも、中の強さなら23.3円。最大の半分です。
4. 1日6時間、30日だと、差は月4185円。
5. 乾燥しにくく静かなのが良さ。暖まったら強さを下げて使いましょう。
6. 単価は目安の31円。あなたの単価は検針票で確かめてください。

説明文：
```
オイルヒーターの電気代、最大と中で月4,185円の差。前提：単価31円/kWh・1日6時間・30日。機種：デロンギ RHJ35M1015。数字の出どころ：セレクトラ（2026/10/30） #電気代 #暖房 #オイルヒーター #節約 #冬支度
```

## 02：寝るとき、エアコンと電気毛布 1か月の差は？

読み上げ（場面ごと）：
1. 寝る8時間を30日。エアコンは930円から4821円、電気毛布は179円。
2. エアコンは強さで大きく変わります。
3. エアコンを止めて、とは言いません。冷えた部屋は体にこたえます。
4. 寝る前まではエアコンで部屋を、寝たら電気毛布で体を暖める。
5. 単価は目安の31円。あなたの単価は検針票で確かめてください。

説明文：

## 03：エアコン、最小と最大で何倍？

読み上げ（場面ごと）：
1. 同じエアコンでも、1時間3.9円から43.1円。
2. 運転の強さで約11倍違います。
3. 強く動くのは設定温度に届くまで。届いたら弱い運転に下がります。
4. だから風量は自動に。フィルターの掃除も強い運転を減らします。
5. 単価は目安の31円。あなたの単価は検針票で確かめてください。

説明文：
```
エアコンの暖房、同じ機種でも1時間3.9〜43.1円（最小〜最大）。前提：単価31円/kWh。機種：パナソニック CS-283DFL（8〜12畳）。出どころ：セレクトラ（2026/10/30） #電気代 #エアコン #暖房 #節約 #冬支度
```
