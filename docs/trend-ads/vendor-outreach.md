# 製品の会社への問い合わせの進め方と文面 2026-11-04

## 結論
- **今いきなり「販売の条件」を交渉しに行くのはやめる。** 月に何件売れるかを聞かれたとき、答える材料が無い。最初の印象で「組む相手ではない」と判断されると、後で取り返しにくい。
- **今すぐ送ってよいのは、材料が要らない問い合わせだけ。** ①資料と無料試用の申し込み（比べて評価するためと正直に書く）、②紹介の制度があるかどうかの確認（件数の約束はしない）。
- **4週間で材料を作ってから、正式に条件を交渉する。** 材料の本命は「見込み客を集められる証拠（業種を絞った相談の件数）」。

## 交渉の材料（武器）と作り方
| 材料 | 中身 | いつまでに |
|---|---|---|
| ① 見込み客を集める力 | 選んだ業種向けの「シャドーAI 対策の選び方」ページと無料相談で、4週間に集めた相談・先行登録の件数（業種と人数つき） | 12/16 |
| ② 業種の専門性 | 1業種の困りごとの調査（現場の声・取引先や行政の要求・払った跡） | 11/18 |
| ③ 製品の理解 | 試用で4製品を比べた中立の評価表（検知の範囲・誤検知・導入の手間・価格） | 12/2 |
| ④ 体制 | 合同会社、広告運用10年、法人営業の経験 | 今ある |
| ⑤ 件数の見込み | 最初は月1〜3社の紹介、3か月後に月5社が目標（事業計画の数字から） | 12/16 に実数で置き換え |

守ること：利用者のふりはしない。比べて評価する目的と、将来の提携を考えていることを最初に書く。

## 追記（11/4）：競合を作ってはいけない条項への備え

### 結論
条項の恐れがあっても、販売から入る。ただし「売る物」と「作る物」を分け、契約で次の線を守る。線を越える条件しか出ない相手とは組まない。

### 売る物と作る物を分ける
| | 売る（他社製品） | 作る（自社） |
|---|---|---|
| 中身 | その場で入力を止める製品、Google・Microsoft の教育向け環境の設定 | 公式の利用記録を読んで点検し、国の点検項目に沿った報告書にする仕組み |
| 関係 | 補い合う（止めた後・使った後の点検と報告） | 同じ機能は作らない |

### 契約の線引き
| 条項 | 判断 | 理由 |
|---|---|---|
| 契約中、同じ機能の他社製品を扱わない | のむ | 同じ機能は作らない方針なので失うものがない |
| 契約中、「生成AI 関連」など広い範囲を扱わない | 範囲を「同じ機能」に絞る交渉。絞れなければ組まない | 作る物（点検と報告）まで縛られる |
| 契約終了後も競合を作らない・扱わない | 削除を求める。残すなら秘密情報の流用防止に限り6か月以内 | 流通・取引慣行ガイドラインでは、総代理店の契約終了後の競争品の制限は原則問題とされ、秘密情報の流用防止に必要な範囲・短期間なら認められる（要原文確認） |
| 1社の製品しか扱えない（独占） | 最初の1年はのまない | 「中立に比べて選ぶ専門家」という差別化が消える |
| 紹介した顧客を自社の製品に切り替えない、顧客名簿は先方のもの | のまない | 販売で積み上げる一番の資産（顧客と困りごとの記録）を失う |

### 販売で積み上げる数字（2027/3まで）
- 学校・教育委員会との面談 20件
- 困りごとの記録 20件（同じ不足が10件以上そろったら、自社で作る判断をする）
- 紹介・販売の契約 2件
