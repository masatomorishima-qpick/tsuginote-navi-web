## 2. 出来事の型 → 訴求軸 → キーワードの作り方

| 出来事の型 | ページの訴求軸（見出しの型） | キーワードの作り方（〈固有名〉×〈出来事〉×〈行動〉） |
|---|---|---|
| 値上げ | 「いくら上がる？乗り換えたらいくら？」 | 〈事業者〉 値上げ いつから／〈事業者〉 値上げ 乗り換え／〈プラン名〉 値上げ |
| サービス終了・障害 | 「代わりはこれ。移行の手順」 | 〈サービス名〉 終了 代わり／〈サービス名〉 移行／〈サービス名〉 障害 乗り換え |
| 新制度・補助金 | 「あなたは対象？いくらもらえる？」 | 〈制度名〉 対象／〈制度名〉 いくら／〈制度名〉 申請 方法 |
| 公的な割引・再販 | 「どこでまだ予約できる？再開はいつ？」 | 〈割引名〉 再開／〈割引名〉 〈予約サイト〉／〈割引名〉 残り |
| 新発売・新作 | 「どれが合う？前のモデルとの違い」 | 〈商品名〉 発売日／〈商品名〉 予約／〈商品名〉 違い |
| 規制・義務化 | 「期限までに何を準備する？」 | 〈制度名〉 準備／〈制度名〉 期限／〈制度名〉 チェック |

広告文の決まり：事業者名・サービス名は、その案件の掲載条件で禁止されていなければ使う。禁止なら「大手3社」「あのプラン」のように言い換える。「必ず」「最安」は使わない。災害・人の死去は見出しに入れない。

除外キーワード（共通）：株価、求人、転職（転職の業種以外）、ニュース、速報、まとめ、2ch、なんj、pdf、英語、とは（制度の説明を探す人は、ページ側で受けるときだけ外す）。

## 3. 速攻の手順（検知から配信まで24時間）

| 時間の目安 | すること |
|---|---|
| 0 | 検知（専門メディア・監視語・急上昇） |
| +30分 | 判定：出来事の型に当たるか、紹介先があるか、ページの型に収まるか。合わなければ記録して終わり |
| +2時間 | ページ：既存のページに入口を足す（見出し1行＋最初の質問の差し替え）。既存がなければ型から新規（診断・計算・比較の設定ファイルを書く） |
| +3時間 | 広告：広告グループを1つ。新しい言葉を3〜5語（フレーズ一致・完全一致）、見出しを5本、除外キーワード。入札の上限は「報酬×見込みの申込率×0.4」 |
| +3.5時間 | 止めた状態で提示。オーナーが了承したら配信 |
| 〜7日 | 1万円か7日で判定：送客率15%以上、単価が上限の1.5倍以内、成果1件 |

提携が要る案件は、検知した日に申請する（即時提携を優先）。承認を待つ間にページと広告を作り、止めた状態で置く。

## 4. 毎朝の監視語（Yahoo!リアルタイム検索で投稿数の推移を見る）

共通の出来事語：値上げ、サービス終了、改悪、再販、再開、補助金、無償化、義務化、新制度、乗り換え、解約、移行
業種の語（上の表の「SNSの監視語」）と組み合わせ、前日比で3倍を超えた語だけ中身を読む。
